Crux: installable version
=========================

1. Upload everything in this folder (keep index.html at the top level) to any
   HTTPS static host, for example Netlify or GitHub Pages.
2. Open the address on your Android phone in Chrome.
3. Chrome menu (three dots) > Install app.

Your log is stored on the phone. Use Settings > Export backup now and then.

When you upload a newer version of these files, change CACHE='crux-v1' to
crux-v2 (then v3, ...) in sw.js so phones pick up the update.

fonts/ contains Bricolage Grotesque (SIL Open Font License, see the license file).
